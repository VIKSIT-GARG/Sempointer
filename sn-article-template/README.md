# Supplied Springer template

This is the user-supplied Springer Nature `sn-jnl` template. The camera-ready source uses unchanged copies of `sn-jnl.cls` and `bst/sn-mathphys-num.bst`. The supplied package identifies itself as a journal template; conference applicability to the named ICT Series must be confirmed with the organizers. Keeping the original template and manual supports that check. The manuscript does not modify class margins or body font sizes.
