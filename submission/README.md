# Camera-ready source

`camera_ready/main.tex` is the current camera-ready manuscript. The directory contains its bibliography, supplied template files, figures, and supporting evidence. Build instructions are in `camera_ready/README.txt`.

The canonical eleven-page PDF is `../output/pdf/SemPointer_camera_ready.pdf`; the source bundle is `../output/submission/SemPointer_source.zip`. Historical build snapshots remain locally for provenance and are ignored by Git.
