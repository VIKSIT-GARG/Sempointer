\label{sec:arch}
\subsection{Six-stage lifecycle}
Long context is addressable blocks with a fixed lifecycle: Segment $\to$ Encode $\to$ Store $\to$ Select $\to$ Fuse $\to$ Resolve.
(1) \textbf{Segment:} partition input into blocks of at most $B$ tokens, deterministic boundaries.
(2) \textbf{Encode:} map each block to one pointer plus a dense embedding.
(3) \textbf{Store:} retain pointers, embeddings, verbatim text in a flat store.
(4) \textbf{Select:} retrieve top-$m$ shortlist under a global token budget.
(5) \textbf{Fuse:} concatenate selected blocks in source order into one prompt.
(6) \textbf{Resolve:} run the frozen reader once, return its answer.

\subsection{Two-stage selection}
Coarse-to-fine.
Stage 1 is $O(1)$-per-block prefilter over pointer codes, after landmark routing~\cite{mohtashami2023landmark} and KV triage~\cite{behnam2025rocketkv}: discards irrelevant blocks without dense comparison.
Stage 2 reranks the shortlist by query-block cosine, keeping top-$m$.
Cost is $O(N+c\cdot d)$ ($N$ blocks, shortlist $c$, width $d$); dense work never scales with full length.

\subsection{Adaptive per-block budgets}
Capacity is not uniform.
Block $i$ gets $k_i$ proportional to salience (length, entity density, novelty), $\sum_i k_i \le K$.
Dense blocks keep more symbols; boilerplate fewer.
Unlike fixed per-token eviction~\cite{li2024snapkv}, budgets adapt pre-query, bounding footprint while informative regions keep resolution.

\subsection{Lifecycle operations}
Four ops mutate the store.
\texttt{REBIND} [specified-not-implemented]: re-encode edited block, replace pointer, preserve identity.
\texttt{FORGET} [specified-not-implemented]: tombstone block, exclude from selection; fail-closed (miss returns empty).
\texttt{ALIAS} [specified-not-implemented]: bind two surface forms to one identity, no duplication.
\texttt{DEREF} [specified-not-implemented]: resolve pointer to verbatim text at fuse time.
Semantics only; no persistence, concurrency, or garbage collection claimed.
Agent memories~\cite{chhikara2025mem0,rasmussen2025zep,packer2023memgpt} motivate these ops, scoped here to prompt-session blocks.

\subsection{Query-aware scoring}
Quest-shaped~\cite{tang2024quest}: the query selects blocks, not static salience.
One query encoding, compared per-query (not per-decoding-step).
No per-token attention surgery and no cross-block KV reuse~\cite{yao2025cacheblend}; reader sees fused text only, so frozen black-box readers work.

\subsection{What was not taken}
\textit{LLM paging loops}~\cite{packer2023memgpt}: multi-call latency and nondeterminism outside a single-pass budget.
\textit{Custom attention ops}: kernel changes break black-box CPU-only compatibility.
\textit{Full-KV retention}: memory scales with context length and breaks the bounded-$K$ goal.
