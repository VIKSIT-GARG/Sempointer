\section{Formal model: semantic pointers}
\label{sec:formal}
Compression shortens blocks. A pointer is short string $p$ holding only address into substrate $S$ disjoint from prompt, plus operator $R$ with $R(p)$ returning verbatim. Compression saves tokens; indirection relocates.

Each $B \in S$:
\[
p = \mathrm{Addr}(B; \theta)
\]
sharing $\theta$ (seeds, codebook); $p$ location, not content.

Fidelity: bounded round-trip distortion:
\[
d(B, R(p)) \le \epsilon
\]
for $d$, $\epsilon$; else dangling address.

\textbf{Ax1 identity [stipulated]:} live blocks have one canonical address. \textbf{Ax2 compactness [measured]:} pointer $k \ll B$ tokens, targeting 10--15x reduction. \textbf{Ax3 stability [stipulated]:} re-addressing unchanged block repeats address. \textbf{Ax4 fidelity [measured]:} resolved text meets $\epsilon$-bound (dense tie, no superiority claimed). \textbf{Ax5 selectivity [measured]:} retrieval reads $m \ll N$ blocks/query. \textbf{Ax6 reusability [stipulated]:} one address serves many dereferences without rebinding. \textbf{Ax7 compositionality [untested--negative]:} $p_1 \oplus p_2$ resolves jointly; pointer strings inert, so $\oplus$ specified, unevidenced.
