## Reproduce the document without inference

From the workspace root:

```bash
experiments/.venv-local-suite/bin/python paper/build_revision_tables.py
mkdir -p paper/build/ten_page
cd paper
tectonic main.tex --outdir build/ten_page --keep-logs --keep-intermediates --reruns 3
```

The resulting submission PDF is `paper/build/ten_page/main.pdf`; `pdfinfo` and the final verification record confirm ten pages total. The body font, class, and margins retain the existing LNCS template. Compact tables use the standard footnote-size table font; no page scaling, negative spacing, or geometry changes are used. To rebuild the extended report separately, run `tectonic extended.tex --outdir build/benefits_focus --keep-logs --keep-intermediates --reruns 3` from `paper/`; this writes `extended.pdf` and preserves the earlier `main.pdf`. The existing historical tables remain checked in locally; regenerate them only if needed with `experiments/warden/bin/python paper/build_results.py` from the workspace root. Historical figures are retained but are not used in this revision. A document build requires no model loading, GPU inference, Modal access, or cloud spending.

Reproducing the two CPU analyses is separate from building the manuscript. Their CLIs reject existing output destinations, so use distinct new output folders. From `experiments/`:

```bash
CUDA_VISIBLE_DEVICES='' .venv-local-suite/bin/python -m analysis.fixed_payload_control --output /absolute/new/control-output
CUDA_VISIBLE_DEVICES='' .venv-local-suite/bin/python -m analysis.audit_bounded_losses --output /absolute/new/audit-output
```

These commands read already-saved model outputs. The fixed-payload control is a retrospective secondary analysis, not an independent new inference run.

The build command uses four TeX passes explicitly, which avoids Tectonic 0.15 reporting repeated bibliography-change consistency warnings. Final labels, citations, table widths, and rendered pages are checked separately.

## Interpretation checks

- The three budgets reuse the same 1,000 questions. Skips are explicit; heterogeneous metrics are not averaged into overall accuracy.
- New generation time includes prefill and decode, excludes ingestion/shared prompt preparation, and differs from historical answer-call timing.
- The active-descriptor control is 990 pairs, 134 wins / 730 ties / 126 losses; the ten null interventions make all-pair totals 134 / 740 / 126.
- Variable tracking is 17 questions, 12 / 5 / 0, 74.12 versus 37.65. Holm is 0.026 over 53 eligible groups and 0.060 over all 123 inspected groups. It remains exploratory; budget-filling BM25 scores 96.47 on those same questions.
- The 229 losses are lower metric scores, not 229 verified factual failures. Fine-grained coverage partitions 18 + 9 + 16; 11 have coarse labels; 175 lack usable aligned fine annotations.
- Main-study limitations include one quantized checkpoint, exposed tests, source overlap, lexical metric artifacts, no Adaptive-k comparison, and length/position confounding in the whole-section control.
- The extended report lists all 123 active task/metric groups; the submission retains all 25 positive rows and complete global/family outcomes. The full distribution is: 25 positive, 22 negative, 76 zero mean differences. Five families have positive win balances. Many individual groups are small; only variable tracking passes the narrower eligible-family Holm adjustment.
- Historical V1, development, and pilot positives retain their own sample sizes, baselines, and complementary outcomes. They are not replications of the bounded full-study descriptor effect.
- Nothing in this revision establishes publication acceptance, official benchmark standing, cross-model robustness, or completion of missing experiments.
