# results_archive/

**Historical artifacts from the pre-reconstruction experiment suite (E01–E17), 2026-09-23/24.**

These outputs were generated by the legacy runners in `archive/legacy_runners/`.
The forensic audit (`INDEPENDENT_RECONSTRUCTION.md`, 2026-09-28) established that:

- The artifacts ARE genuine outputs of that code (fresh runs reproduce them).
- However, the suite involves **no LLM inference and no public datasets**:
  - E02/E11 "QA accuracy" is substring containment, not model generation.
  - E05's "empirical" K* is the theoretical value assigned to itself.
  - E14's M_kv row is hardcoded constants; M_latent is an untrained random MLP.
  - E15/E16 numbers are closed-form formula evaluations, not measurements.
  - Several numbers quoted in the paper's evaluation section contradict these
    artifacts (see INDEPENDENT_RECONSTRUCTION.md §7).

They are preserved here for auditability only. **None of these numbers may be
cited as current experimental evidence.** Current results live in `results/`.
