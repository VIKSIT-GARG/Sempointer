# Experiment results inventory

This directory preserves completed experiments, development runs, historical comparisons, and diagnostic or partial attempts. Each immediate run directory has a scope note; dataset counts and smoke tests do not establish benchmark completion. The canonical manuscript is `submission/camera_ready/main.tex` and its camera-ready PDF is `output/pdf/SemPointer_camera_ready.pdf`.

The root repository versions code and summaries. Heavy databases, input contexts and large event streams may remain locally ignored and are cataloged by a SHA-256 evidence manifest. An ignored artifact is still evidence and must not be deleted on that basis. Preserve SQLite databases with their WAL/SHM sidecars, predictions, configurations, frozen source inputs, manifests and reports. See `docs/EVIDENCE.md` for the run map and the separate incomplete Kaggle archive caveat.
