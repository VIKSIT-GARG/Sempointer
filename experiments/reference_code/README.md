# Frozen implementation snapshots

Each dated directory preserves implementation bytes and its original manifest at a research transition: before Qwen3.5, cloud preparation, precision selection, or bounded descriptors. These are provenance inputs, not alternative active implementations. Keep source snapshots and manifests together; never silently replace them with current code. The current implementation lives in the sibling `sempointer/`, `evaluation/`, and `analysis/` directories.

The project evidence inventory fingerprints these snapshots. Bytecode caches are excluded; no source file was changed by cleanup.
